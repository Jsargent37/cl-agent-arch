# Verdict Vocabulary

Shared verdicts used by `distill`, `drift-check`, and `graduate-to-template` when proposing
changes to skills, agents, or registry entries — one vocabulary so reports read consistently
across all three.

- **Keep** — useful and current, no change needed.
- **Improve** — needs specific changes; name them.
- **Update** — outdated references; name them.
- **Retire** — low quality or stale; say why.
- **Merge into `<target>`** — overlapping content with `<target>`; name it.

Every verdict needs a concrete, evidence-based justification. "Unchanged" alone is not a
justification — restate why it's still correct.
