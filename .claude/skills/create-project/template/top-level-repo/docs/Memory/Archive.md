# __REPO_NAME__ Memory Archive

Full text of Procedures entries collapsed after graduating into a skill or
tool (see [Procedures](Procedures.md) `distilled_into`). Kept for history
and provenance only.

**This file is intentionally excluded from every required-read list** —
onboarding, task start, and closeout never require reading it. Consult it
manually when you need the pre-collapse detail behind a graduated
procedure.

## Archived Entries

### example-archived-entry
```yaml
collapsed_on: __DATE__
distilled_into: example-skill-id
original_promotions: 3
episodes: ["episode-name-1", "episode-name-2", "episode-name-3"]
```
Original body:
```yaml

  - "The second step, preserved verbatim."
```
