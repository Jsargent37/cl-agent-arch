# Archive

Full text of `PROCEDURES.md` entries collapsed after graduating into a real skill or tool (see
`PROCEDURES.md`'s `distilled_into` field). Kept for history and provenance only.

**This file is intentionally excluded from `registry_index.py`'s `REGISTRY_FILES`** — it never
appears in the relevance-check index, and no onboarding or task-start flow requires reading it.
Consult it manually when you need the pre-collapse detail behind a graduated procedure.

## Archived Entries

_None yet._

## Update Rule

- Written only by `distill`'s Graduate step (step 5), when a procedure's `distilled_into` gets set.
- An archived entry's `id` always matches the original `PROCEDURES.md` entry's id, so the two stay
  traceable to each other even though `distilled_into`'s value is the graduated skill/tool's own id
  (a different string).
- Never delete an archived entry, even if the skill/tool it points to is later retired — it remains
  the permanent record of what the procedure used to say.
