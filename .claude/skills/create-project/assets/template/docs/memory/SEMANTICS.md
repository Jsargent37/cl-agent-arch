# Semantics

Project language + applicability-tag vocabulary. Every `applicability` tag used elsewhere in the
registries must exist as an entry id here first.

## Entries

### episode
```yaml
summary: The durable, append-only record of one task/session, in docs/episodes/.
episodes: []
```
- Supported by: (none yet)

### memory-registry
```yaml
summary: The curated knowledge layer -- the four docs/memory/*.md registries (GUARDRAILS, PROCEDURES, LESSONS, SEMANTICS) plus docs/memory/promotion-drafts/ for long-form content.
episodes: []
```
- Supported by: (none yet)

### promotion
```yaml
summary: Moving a durable term, rule, or lesson from an episode into the registries at closeout.
episodes: []
```
- Supported by: (none yet)

### code-standards
```yaml
summary: Tag for topics governed by docs/CODE_STANDARDS.md.
episodes: []
```
- Supported by: (none yet)

### python-environment
```yaml
summary: Tag for topics about this project's local uv virtual environment and Python dependency management.
episodes: []
```
- Supported by: (none yet)
